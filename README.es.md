Copia JSON/CSV de un libro mayor de clasificación. Cada fila tiene un `source_url` público.

**Sitio canónico: [https://aiwenbiao.cn/data](https://aiwenbiao.cn/data)**  
Inicio oficial: [https://aiwenbiao.cn](https://aiwenbiao.cn)

No es un comité de evaluación, ni una oficina estadística, ni un ranking de adjudicación. Sin URL pública no hay fila. Se exige revisión humana; no se garantiza ganar.
